# React 심화 가이드

[백엔드 개발자를 위한 프론트엔드 가이드](../README.md)의 **동반 문서**입니다.
입문 가이드가 "React로 화면을 만들 수 있게" 만든다면, 이 문서는 **"React가 내부에서 무슨 일을 하는지 알고 쓰게"** 만드는 것이 목표입니다.

## 누구를 위한 문서인가

- 입문 가이드 Part 4(16~20장)를 읽었거나, React로 화면을 몇 개 만들어 본 사람
- 동작은 하는데 **왜 되는지 / 왜 가끔 안 되는지** 를 설명하지 못하는 사람
- 코드리뷰에서 "이건 리렌더 때문에 위험해요" 같은 말을 듣고 반박도 수긍도 못 했던 사람

**선수 지식**: 입문 가이드 Part 1~2(브라우저·JS·TS). 특히 [6장 이벤트 루프](../docs/01-브라우저라는-런타임/06-싱글-스레드와-이벤트-루프.md), [8장 클로저](../docs/02-언어-JS와-TS/08-함수가-일급-시민이라는-것.md), [11장 TypeScript](../docs/02-언어-JS와-TS/11-TypeScript.md)는 이 문서 전반에서 계속 쓰입니다.

## 이 문서가 다르게 하는 것

입문 가이드가 "이렇게 쓰면 됩니다"라면, 이 문서는 **"React는 이 규칙에 따라 이렇게 동작하고, 그래서 이렇게 써야 합니다"** 입니다.

- 모든 규칙에 **왜 그런 규칙이 생겼는지**를 붙입니다 (Hooks를 조건문에 못 쓰는 이유 같은 것)
- 흔한 조언을 그대로 옮기지 않고 **언제 틀리는지**까지 씁니다 (`useMemo`를 다 붙이면 안 되는 이유 같은 것)
- 각 장 끝에 **안티패턴** 을 하나씩 쌓아서 마지막 장에서 체크리스트로 모읍니다
