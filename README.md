## 집필 규칙

1. **모든 개념에 BE 앵커를 붙인다** — 새 개념은 항상 "당신이 이미 아는 그것"으로 시작
2. **개념 부채 0** — 앞에서 정의하지 않은 용어는 뒤에서 쓰지 않는다
3. **"왜"가 먼저, "어떻게"는 나중** — 도구 나열식 금지
4. **한 장 = 15분 = 질문 하나** — 코드 조각은 20줄 이하
5. **장별 골격 고정** — 이 장의 질문 → BE로 치면 → 문제 상황 → 개념+도표 → 코드 읽기 → 흔한 오해 → 핵심 3가지 → 스스로 답해보기 2문항
