# 리뷰 기록

이 자료는 작성 후 **Codex 에이전트로 교차 검수**를 거칩니다. 각 라운드의 지적사항 원본을 남겨 둡니다.

| 라운드 | 파일 | 범위 |
| --- | --- | --- |
| 1 | [round-1-codex.md](round-1-codex.md) | 입문 1~15장, 심화 1~4장 — 사실 오류, 개념 부채, BE 비유, 난이도, 두 문서 간 중복 |
| 2 | [round-2-codex.md](round-2-codex.md) | 1차 반영 검증 + 입문 16~20장 + 한글 가독성 |

## 검수 기준

1. **기술적 사실 오류** — 브라우저 동작, React 19, Next.js App Router 서술 중 틀렸거나 낡은 것
2. **개념 부채** — 앞 장에서 정의하지 않은 용어를 뒤 장에서 설명 없이 쓴 곳 (집필 원칙 2번)
3. **BE 비유 과잉** — 비유가 오히려 잘못된 모델을 만드는 곳
4. **난이도 급등** — 독자가 막힐 지점
5. **문서 간 중복·누락** — 입문 가이드와 심화 가이드 사이
6. **한글 가독성** — 긴 문장, 모호한 지시어, 번역투 (2라운드부터)

## 리뷰를 받아들이는 방식

리뷰어도 틀립니다. **모든 지적은 실제 파일에 대조한 뒤 반영합니다.**

2차 리뷰에서는 A·C 섹션의 파일 경로가 실재하지 않는 것으로 확인됐습니다(예: `docs/01-웹-브라우저와-인터넷/…`). 지적 내용 자체는 다수가 유효했지만, 이미 고친 것을 다시 지적한 항목도 섞여 있었습니다. 원문을 그대로 보존해 두는 이유가 이것입니다.
