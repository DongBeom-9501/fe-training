# 부록 A. FE ↔ BE 용어 대응표

프론트엔드 용어를 만날 때마다 여기서 "내가 아는 그것"을 찾으세요. 각 항목은 **엄밀한 등가가 아니라 이해를 위한 앵커**입니다. 어긋나는 지점은 오른쪽 칸에 적어 두었습니다.

## 구조와 빌드

| FE 용어 | BE로 치면 | 어긋나는 지점 |
| --- | --- | --- |
| `package.json` | `build.gradle.kts` / `pom.xml` | 스크립트 실행기 역할까지 겸합니다 |
| `node_modules` | `~/.m2`, `~/.gradle` 캐시 | 프로젝트마다 로컬에 복사됩니다 (31장) |
| `package-lock.json` / `pnpm-lock.yaml` | `gradle.lockfile` | 커밋 필수입니다 |
| npm / pnpm / yarn | Maven / Gradle | |
| 번들러 (Vite, webpack) | Gradle의 컴파일 + 셰이딩 | 결과물이 JAR이 아니라 브라우저용 JS 파일 (32장) |
| 트랜스파일 (Babel, SWC) | 바이트코드 타깃 다운그레이드 | 구형 브라우저 대응 |
| 트리 셰이킹 | 미사용 클래스 제거 (ProGuard) | |
| 코드 스플리팅 | 모듈 분리 + 지연 로딩 | 네트워크로 나눠서 받는다는 게 핵심 |
| 소스맵 | 디버그 심볼 | |

## 언어

| FE 용어 | BE로 치면 | 어긋나는 지점 |
| --- | --- | --- |
| `undefined` | (대응 없음) | `null`과 별개입니다 — 7장 |
| `null` | `null` | |
| 클로저 | 람다가 캡처한 변수 | 참조를 캡처합니다 (8장) |
| `map` / `filter` / `reduce` | Stream API | 지연 평가가 아니라 즉시 평가 |
| `Promise` | `CompletableFuture` | |
| `async / await` | 코루틴 `suspend` | 스레드가 하나뿐이라 성격이 다릅니다 (9장) |
| 이벤트 루프 | 단일 스레드 이벤트 디스패처 | 스레드풀이 없습니다 (6장) |
| ESM `import` | `import` | 파일 경로 기반 |
| 구조적 타이핑 | 덕 타이핑 + 컴파일 타임 검사 | 이름이 아니라 모양으로 판단 (11장) |
| `any` | `Object` 캐스팅 남발 | 타입 검사를 통째로 끕니다 |
| 제네릭 | 제네릭 | 소거가 아니라 애초에 런타임에 없음 |

## 화면

| FE 용어 | BE로 치면 | 어긋나는 지점 |
| --- | --- | --- |
| DOM | 파싱된 문서의 객체 트리 | 살아 있고 계속 변합니다 (5장) |
| 컴포넌트 | 재사용 가능한 서비스/모듈 | 상태와 화면을 함께 캡슐화 |
| props | 생성자 파라미터 | 불변입니다 (17장) |
| state | 인스턴스 필드 | 바뀌면 화면이 다시 그려집니다 (18장) |
| 리렌더 | 요청 재처리 | 결과가 같으면 화면은 안 바뀝니다 |
| 재조정 (reconciliation) | diff 후 최소 변경 적용 | (18장) |
| `key` | 엔티티의 PK | 목록에서 동일성 판단 기준 |
| Hook | 컴포넌트 생명주기에 거는 훅 | 호출 순서에 규칙이 있습니다 (19장) |
| CSS 특이성 | 설정 오버라이드 우선순위 | (13장) |

## 데이터와 상태

| FE 용어 | BE로 치면 | 어긋나는 지점 |
| --- | --- | --- |
| 서버 상태 | DB에 있는 데이터의 **캐시 복사본** | 원본이 아니라는 게 핵심 (26장) |
| 클라이언트 상태 | 세션 스코프 빈 | 사용자 기기에만 존재 |
| URL 상태 | 요청 쿼리 파라미터 | 공유·북마크 가능해야 함 (29장) |
| `staleTime` | 캐시 TTL | (27장) |
| 무효화 (invalidation) | 캐시 evict | |
| 낙관적 업데이트 | 응답 전 선반영 후 보상 트랜잭션 | (27장) |
| 하이드레이션 | 직렬화된 상태로 객체 복원 | 서버가 만든 HTML에 이벤트를 다시 붙이는 것 (22장) |

## 런타임과 배포

| FE 용어 | BE로 치면 | 어긋나는 지점 |
| --- | --- | --- |
| CSR | 클라이언트가 조립 | 초기 화면이 늦습니다 (21장) |
| SSR | 서버 사이드 템플릿 렌더링 | JSP/Thymeleaf와 가장 가까움 |
| SSG | 빌드 타임 정적 생성 | |
| ISR | TTL 지난 뒤 백그라운드 재생성 | 캐시 스탬피드 방지와 같은 발상 |
| 서버 컴포넌트 (RSC) | 서버에서만 도는 렌더 로직 | DB를 직접 호출할 수 있습니다 (24장) |
| CDN | 리버스 프록시 캐시 | 전 세계 엣지에 배포 |
| Core Web Vitals | SLI/SLO | 사용자 체감 지표 (34장) |
| 정적 호스팅 | 서버 없는 파일 배포 | (33장) |
